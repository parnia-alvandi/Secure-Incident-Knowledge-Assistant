# Baseline RAG demo (Task 2)

All outputs below were produced by `scripts/eval_baseline.py` on this machine and are reproduced unedited. Nothing was re-run or hand-picked for this document.

## Setup

- LLM: qwen2.5:3b-instruct via Ollama (temperature 0.0, num_ctx 4096, num_predict 300), local CPU
- Embedding model: BAAI/bge-small-en-v1.5
- Prompt: version 1 (max 1 repair retry)
- Retrieval: vector search (Chroma, cosine), top-5; evidence gate off
- Index: 35 documents, 1510 chunks, chunking 256/40/40 (size/overlap/min tokens), built 2026-11-22T08:51:37+00:00
- Libraries: python 3.11.9, sentence-transformers 5.7.0, chromadb 1.5.9, numpy 2.4.6, pypdf 7.1.0, python-docx 1.2.0

## How the questions were chosen

The evaluation set is every English unanswerable question plus 40 answerable ones (half public documents, half synthetic), sampled with seed 42 and shuffled with the same seed. This demo shows the **first 5 answerable and the first unanswerable question in that order**. The rule was fixed before looking at outcomes; the full-set results are in the next section.

`answered` means: the model produced an answer with at least one valid citation. It does NOT mean the answer is correct. The verdicts are a human judgement.

## Known limitations

- Single run, 80 questions, written from the same documents: a baseline, not a final evaluation.
- Retrieval is vector-only (hybrid search and re-ranking come in phase 5); the correct passage reached the model for about 80% of the answerable questions.
- Near-miss questions (topic covered, detail absent) are sometimes answered anyway; a check that the answer is supported by the cited passage is planned for phase 7.
- Latency on this CPU is about 30 s per question, dominated by prompt processing.
